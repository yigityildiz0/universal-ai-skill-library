# Rehabilitation program design framework

## Evidence anchors

- [WHO Package of Interventions for Rehabilitation](https://www.who.int/publications/i/item/9789240067097) maps essential interventions across major rehabilitation populations and identifies workforce, equipment, assistive products, and consumables.
- [Consensus on Exercise Reporting Template (CERT)](https://pubmed.ncbi.nlm.nih.gov/27707738/) defines the minimum information needed to describe replicable exercise programs.
- [TIDieR](https://www.bmj.com/content/348/bmj.g1687) structures intervention rationale, materials, procedures, provider, delivery, setting, dose, tailoring, modifications, and fidelity.
- Use current population-specific clinical practice guidelines for safety, eligibility, and disease-specific recommendations.

These are description and implementation frameworks; they do not prove efficacy.

## Dose-provenance ladder

Label every numeric prescription:

1. **Guideline recommendation:** exact source, population, strength/certainty, and whether the number is explicit.
2. **Study protocol dose:** actual randomized/observed dose, adherence, progression, supervision, and exclusions.
3. **Consensus/position statement:** issuing body, population, and evidence basis.
4. **Clinician-titrated starting dose:** individualized from baseline and response; identify that it is not directly established by the cited trial.
5. **Unknown/not reported:** never guess.

## Component specification

| Field | Required detail |
|---|---|
| Why | Target problem, mechanism/rationale, meaningful outcome |
| What | Exercise/task/intervention, materials, equipment, co-interventions |
| Who | Provider competence, patient/caregiver role |
| How | Individual/group, supervised/unsupervised, in-person/remote |
| Where | Clinic, home, community, work, sport environment |
| Dose | Frequency, intensity/load, duration, sets/repetitions, total volume, rest, program length |
| Tailoring | Baseline-based start and adaptations |
| Progression | Explicit decision rule and next change |
| Regression | Modify/hold options |
| Fidelity | What should be delivered and how checked |
| Adherence | Planned and actual exposure, barriers, support |
| Harms | Expected response, adverse event, stop/escalate action |

## Progression logic

Change one main variable at a time when possible. Consider this sequence, adapting by goal:

1. safety and movement/task quality;
2. range, assistance, or environmental demand;
3. volume or time under task;
4. intensity/load/speed;
5. complexity, variability, dual task, perturbation, or context;
6. reduced supervision and transfer to real-life participation.

This is a reasoning scaffold, not a universal rule. Some tasks require a different sequence.

Do not use one generic “pain-monitoring model” for all conditions. Define the relevant response window and acceptable response from condition-specific evidence, tissue/medical context, and patient goals. Unexpected or worsening response triggers reassessment.

## Session template

1. Pre-session safety/status check
2. Patient priority and goal for the session
3. Warm-up or preparation only if useful
4. High-priority skill/strength/endurance/task work in a justified order
5. Education or self-management practice
6. Response monitoring and dose actually completed
7. Home-program rehearsal and teach-back
8. Adverse-event and safety-net review
9. Documentation and next decision point

## Home and remote program gate

Confirm instructions are understandable, equipment is safe, space is suitable, assistance is available when needed, and the person can demonstrate the task. For remote delivery verify physical location, emergency plan, connection failure plan, fall/transfer risk, and whether remote delivery is validated/appropriate.

Never prescribe an unsupervised maximal test, high-fall-risk balance task, or high-risk procedure merely because it appeared in a study.

## Assistive technology pathway

Apply this to gait aids, orthoses, prostheses, wheelchairs/seating, transfer aids, communication/access devices, and other rehabilitation technology:

1. define the activity/participation goal and the environments in which the device must work;
2. assess body functions, cognition/communication, sensation/skin, transfer/fall risk, upper-limb demand, caregiver role, transport, terrain, doorway/home/work constraints, and likely change over time;
3. compare no-device, environmental, training, repair, and device alternatives, including cost, availability, stigma/preferences, maintenance, and funding rules;
4. arrange a real trial and qualified fitting/configuration where required; record the exact model/components and who is responsible;
5. train the user/caregiver in safe use, setup, transfers, skin/pressure checks, charging/maintenance, failure response, and when to stop;
6. measure goal attainment, efficiency, comfort, adverse effects, participation, actual use, and abandonment risk in the intended environment;
7. schedule follow-up for fit, growth/volume/tissue change, wear, repair, and changing goals.

Do not infer safe fit from height alone or fabricate cane/walker height, socket/orthotic alignment, wheelchair dimensions, cushion pressure, electronics, or manufacturer settings. Coordinate with the relevant prosthetist, orthotist, wheelchair/seating clinician, rehabilitation engineer, supplier, or prescriber under local requirements.

## Special-population adaptation

- **Postoperative:** protocol, healing, wound, load, implant, surgeon restrictions.
- **Pediatric:** development, growth, assent/guardian consent, play/participation, safeguarding.
- **Pregnancy/postpartum:** obstetric screening, stage, warning signs, positional/environmental modification.
- **Neurological:** cognition/communication, fatigue, falls, tone, autonomic and seizure considerations.
- **Cardiopulmonary:** disease-specific monitoring, symptoms, prescribed targets, medications, oxygen/device plan.
- **Oncology:** bone stability, counts when relevant, infection/bleeding, cardiotoxicity, fatigue, lines/ports.
- **Pelvic health:** consent, privacy, trauma-informed care, trained provider; no remote internal DIY plan.
- **Frailty/multimorbidity:** recovery, polypharmacy, falls, caregiver/resources, competing risks and priorities.

## Reassessment decisions

Use a decision table:

| Finding | Action |
|---|---|
| Goal-relevant improvement, acceptable response | Continue or progress |
| Adherence/exposure inadequate | Solve barrier before declaring failure |
| No meaningful change despite adequate exposure | Reassess hypothesis, dose, measure, or option |
| New precaution/adverse response | Modify or hold and assess |
| New serious-pathology signal | Stop and escalate |
