# Intake questions

Ask in ONE message, numbered, each with 2–4 concrete options plus "sen karar ver". Offer defaults in brackets. Skip anything the
user already answered. Ask more only when the answer changes the result. Language: the user's.

## Core (almost always)

1. **Ne için?** a) kendi çalışmam / sınav notu b) başkasına gönderilecek (hoca, takım, hasta) c) yazdırılacak d) ekrandan okunacak e) teslim / başvuru / arşiv
2. **Yön ve boyut?** a) dikey A4 [varsayılan] b) yatay A4 c) dikey + geniş tablolar için yatay bölümler d) başka (A5, Letter, kare)
3. **Tasarım dili?** (konuya uygun 3–4 seçenek sun; her biri tek satır)
   - Akademik sade — serifli başlıklar, lacivert + bordo, çok düzenli
   - Klinik temiz — açık zemin, turkuaz vurgu, ferah
   - Editoryal — dergi hissi, büyük başlık, geniş boşluk
   - Teknik rapor — sıkı, numaralı, grafit + mavi
   - Modern kartlı — yumuşak paneller, büyük sayılar
   - Minimal siyah-beyaz — yazıcı dostu
4. **İçerik nereden gelecek?** a) yüklediğim dosyalar / yapıştırdığım metin b) konuyu sen araştır (kaynaklı) c) ikisi birden — ve hangi dosyalar esas?
5. **Uzunluk ve yapı?** a) kısa (1–2 sayfa) b) orta (3–10) c) uzun (10+) d) sayfa sayısı: __ — kapak, içindekiler, kaynakça olsun mu?

## Depending on the answers

- **Kaynak ve alıntı:** atıf stili (APA 7 varsayılan), kaynaklar sayfa sonunda mı bölüm sonunda mı, hangi tür kaynak kabul?
- **Görseller ve tablolar:** hazır görsel var mı; yoksa gerçek/lisanslı mı aranacak, şematik çizim mi; tablolar geniş olabilir mi?
- **Dil ve ton:** Türkçe/İngilizce, resmi/samimi, "ben" mi "biz" mi, terimlerde İngilizce karşılık parantezle mi?
- **Marka:** logo, kurum rengi, yazı tipi zorunluluğu, şablon var mı?
- **Okuyucu:** önceden bilgisi ne kadar? Terimler açıklanacak mı? Özet kutusu/"Özetle" istiyor mu?
- **Yazdırma:** siyah-beyaz mı, çift taraflı mı (cilt payı), ofis yazıcısı kenar payı?
- **Erişilebilirlik:** büyük punto, yüksek kontrast, sesli okuyucu uyumu gerekli mi?
- **Veri:** sayılar için birim, ondalık ayracı (virgül), tarih biçimi.
- **Dosya adı ve yer:** nereye kaydedilecek, adı ne olsun, kaynak HTML de teslim edilsin mi?

## How to ask well

- Group questions; never drip them one by one.
- Show what each option looks like in a short phrase, not a lecture.
- When the user is vague, propose a full default set in one line ("A4 dikey, Klinik temiz, kapaksız, 6–8 sayfa") and ask "Böyle olur mu?".
- Record the answers at the top of the working folder (`brief.md`) and reuse them for the next PDF in the same project.
- If the user later asks for something that contradicts a rule in this skill, ask the conflict question (rule or wish; this
  document or always) and store the answer.
