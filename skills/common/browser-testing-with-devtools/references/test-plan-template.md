# Focused Browser Test Plan

```text
Requirement / risk:
Environment and build:
Authorized account or fixture:

Initial state:
Actions:

Evidence to capture:
```

Use the smallest matrix that covers meaningful risk. A plan is not a license to create accounts, purchase, send messages, or mutate production data.
