# General (non-academic) presentations

Project updates, class projects outside a lecturer's rules, business pitches, reports, workshops,
personal talks. Same pipeline, same QA. Differences:

## Defaults that stay

- Safe fonts, role-based sizes, 36 pt floor unless the user sets another (ask via the conflict
  protocol if they ask for smaller), layout variety, real visuals, notes, render + audit.

## Defaults that change

| Topic | General deck |
|---|---|
| Sources | cite data, quotes and borrowed images; no source line on opinion/structure slides |
| Structure | situation → problem → idea/solution → evidence/demo → plan/ask → summary |
| Titles | outcome-first claims ("Kayıtlar 3 ayda %40 arttı") |
| Numbers | big-number slides for the 2–3 figures people must remember |
| Tone | the presenter's natural voice; no hype words |
| Branding | an organisation template overrides theme colours and geometry (not the floor) |
| Notes | same template; ARAŞTIRMA becomes KANIT (data source + how to read it) |

## Common general formats

- **Pitch (8–12 slides):** problem, who has it, solution, how it works (demo/photo), traction
  numbers, business model, competition, team, ask.
- **Project report (10–20):** goal, what was done (timeline/process), results (charts), problems and
  fixes, next steps, decisions needed.
- **Workshop/training:** learning goals, short concept slides, step-by-step practice slides
  (photoSteps), check questions, summary card.
- **Status update (5–8):** traffic-light summary, done / next / risks, one chart.

## Ask only if it changes the result

Audience and goal (inform, convince, decide), time, mandatory template, whether the deck must work
without a speaker (then more text per slide and fuller notes, still within the floor).
