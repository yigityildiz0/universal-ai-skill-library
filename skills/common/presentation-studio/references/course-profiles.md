# Course profiles

Profiles distil rules lecturers gave in class (recordings and course plans) plus the presenter's
accepted decisions. They are defaults: the course's own written plan or a newer instruction from
the same lecturer wins. When a profile leaves something open (marked **sor**), ask once and store the
answer in the brief. Unknown course → `general` profile + ask for the course rules file; offer to
save the rules as `<Ders> - Ders ve sunum kuralları.txt` in the course folder so any AI can read
them next time.

| | `seminar-article` | `measurement-lecture` | `clinical-case` | `general` |
|---|---|---|---|---|
| Typical course | MSc seminar: presenting recent research articles on a topic | MSc measurement & evaluation: one lecture topic taught to classmates | clinical problem-solving: group case presentation | any other talk |
| Floor | 36 pt (lecturer: "absolute") | 36 pt (presenter's rule; lecturer gave none) | 36 pt (lecturer range 32–36) | 36 pt |
| Lines | ≤ 6 (lecturer 6–7; advisor 5–6) | ≤ 6 | ≤ 7 (lecturer 7–8) | ≤ 6 |
| Time | **sor** (not fixed by lecturer); default 30 min | 30–45 min, target 35–40 | 60 min (≈ 50 talk + 10 practice/questions) | ask |
| Slides | ≥ 20 | ≈ 30–40, set by time | ≈ 40–50 incl. short theory | ≈ 1 per minute |
| Sources | recent (mostly 2020+), international clinical studies; **no reviews or systematic reviews** as the presented articles; know journal, impact, authors, country | peer-reviewed articles/books, international; source line on every scientific slide | scientific sources; Turkish sources acceptable; lecture notes not cited with page numbers | peer-reviewed or official |
| Structure | per article: first page of the article (screenshot) → aim → method/material → assessment → results → discussion; then "Ne öğrendim / sınırlılıklar / ben yapsam ne yapardım" | MSc level (not a bachelor's recap); topic headings from the course plan; every slide teaches something new | short pathology/theory (≈ 10–15 slides) → case demographics + photos/videos → ICF-based assessment (both sides compared, reference values) → treatment with "why" → current approaches → practical | agenda → sections → summary |
| Visuals | article first page, figures | photos and short method videos raise the grade | patient assessment/treatment photos or videos **mandatory, with consent** | real photos, charts |
| Text density | concise bullets, interpretation spoken | few words, own sentences, explained aloud | slides not read aloud; presenter may want more informative text — still ≤ 7 lines | concise |
| Extras | research week: ≥ 8 articles; files uploaded the same day (**sor**: second file type); expected questions: what did you learn, limitations, what would you do differently | the deck doubles as a study file: no time-bound wording | group tasks anonymised (A kişisi, B kişisi); cover: course, group, topic, case; translation-sounding sentences are penalised; lecturer discourages AI-written text → write in the presenter's natural voice | — |
| Closing | courtesy sentence in notes: open to criticism and will update the deck | summary answering the agenda | summary + plan | summary |

## Questions a profile may require (ask once, then store)

- Talk length when the profile says **sor**.
- Small section label (20 pt) allowed? Default no.
- Notes abbreviation mode: every mention (default, as the presenter asked) or first mention per
  block then pronunciation only.
- Lecturer name on the cover? Default: small "Ders sorumlusu" line for course talks.
- Mandatory institution template? If yes it overrides theme and layout geometry, not the floor.
