# Source Notes

Use these sources when the facts are unstable or module-specific.

## Prefer These Sources

- ComfyUI docs: [https://docs.comfy.org](https://docs.comfy.org)
- ComfyUI GitHub: [https://github.com/comfyanonymous/ComfyUI](https://github.com/comfyanonymous/ComfyUI)
- BFS model card: [https://huggingface.co/Alissonerdx/BFS-Best-Face-Swap](https://huggingface.co/Alissonerdx/BFS-Best-Face-Swap)
- PuLID Flux2 model card: [https://huggingface.co/Fayens/Pulid-Flux2](https://huggingface.co/Fayens/Pulid-Flux2)
- LanPaint repo: [https://github.com/scraed/LanPaint](https://github.com/scraed/LanPaint)

## Use Source Priority

1. Official documentation
2. Official model cards or official repositories
3. Local runtime evidence
4. Community examples only when they do not conflict with the sources above

## Avoid

- copying random community settings as universal truth
- changing architectures based on one video
- treating popularity as stronger evidence than model-card behavior
