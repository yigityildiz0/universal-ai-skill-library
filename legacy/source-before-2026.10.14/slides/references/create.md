# Create an HTML presentation

Execute this workflow directly; do not invoke `slides` again.

1. Establish audience, objective, duration, evidence, brand and requested output. Use `academic-study-coach` for academic/FTR content and an available presentation tool for editable PPTX.
2. Draft the narrative and one message per slide. Read the relevant strategy, layout and copy references beside this file; adapt persuasion to the audience rather than forcing a sales pitch.
3. Search optional local patterns with `python "<SKILL_DIR>/yigit/scripts/search-slides.py" "<query>" -d strategy`. The database is bundled with this skill.
4. For requested HTML, adapt `html-template.md` or the bundled generator. Use approved project tokens; illustrative defaults are not the user's brand. Supply real chart data and visible text alternatives. Embed required CSS/assets for an offline deliverable or explicitly list remaining network dependencies.
5. Check text fit, keyboard navigation, visible focus, contrast, reduced motion, chart labels and responsive/print behavior using available tools. Static token checks are not visual or accessibility certification.
6. Deliver the requested deck or outline and state what was actually verified. Export additional formats only when requested.
