# Pre-publication rights review

This generated repository is a local staging candidate, not proof of redistribution rights.

Public release is blocked pending a skill-by-skill rights review:

- 405 canonical skills have no local redistribution-license signal.
- 55 skills have a license file but still need upstream identity, revision, copyright, and NOTICE verification.
- `figma-design-system-rules-codex` and the Figma material embedded in `skill-library-router` are governed by supplied terms rather than a confirmed open-source redistribution license.
- `skill-library-router` contains a large vendored library with fonts, images, scripts, and nested third-party material; it must remain excluded from a first public release unless each component is cleared.

Workstation paths, Python caches, unsafe installer examples, and two redundant nested archives are removed by the build. Those cleanups do not cure missing redistribution rights.

The repository-authored catalog, website, packaging metadata, and documentation may be published under `LICENSE.md`; that grant does not cover third-party skill bodies.
